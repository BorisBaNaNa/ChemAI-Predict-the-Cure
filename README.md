# Прогнозирование биологической активности химических соединений

## Описание проекта

В рамках соревнования необходимо разработать модель машинного обучения для предсказания трёх ключевых показателей эффективности химических соединений против вируса гриппа:

- **IC50 (mM)** — концентрация вещества, при которой подавляется 50% активности вируса
- **CC50 (mM)** — концентрация, при которой наблюдается токсичность для 50% клеток
- **SI** — индекс селективности (Selectivity Index), характеризующий эффективность соединения

# Предобработка данных

## Выполняемые этапы

### 1. Замена `inf` на `NaN`

Некоторые химические дескрипторы содержат бесконечные значения, возникающие при вычислении молекулярных характеристик.

Перед обучением:
```python
X.replace([np.inf, -np.inf], np.nan)
```

---

### 2. Удаление константных и квазиконстантных признаков

Удаляются признаки:
- содержащие одно значение
- где одно значение занимает >99% выборки

Это уменьшает:
- шум
- переобучение
- бесполезную размерность пространства признаков

---

### 3. Логарифмирование признаков с большим диапазоном

Для признаков с экстремально большим разбросом:
```python
log1p(x)
```

Это:
- стабилизирует распределение
- уменьшает влияние выбросов
- делает обучение CatBoost устойчивее

---

### 4. Заполнение пропусков

Используется:
```python
SimpleImputer(strategy="median")
```

Медиана выбрана из-за устойчивости к выбросам.

# Методология модели

## Основная идея

Используется ансамбль из двух подходов:

| Модель | Роль |
|--------|------|
| Multi-output CatBoost | Изучает взаимосвязи между таргетами |
| Single-output CatBoost | Специализируется на каждом таргете отдельно |

---

## Почему Multi-output важен

Таргеты физически связаны:

```text
SI = CC50 / IC50
```

Multi-output модель способна:
- учитывать эту зависимость
- использовать совместное распределение таргетов
- улучшать согласованность предсказаний

---

## Поиск оптимальных весов ансамбля

Веса ансамбля не фиксируются вручную.

Используется:
- 5-Fold Cross Validation
- перебор весов от `0.40` до `0.70`

Финальное предсказание:
```python
ensemble =
    weight * multi_output +
    (1 - weight) * single_output
```

---

# Post-processing

## Ограничение выбросов

Предсказания ограничиваются 99-м перцентилем:

```python
np.clip(predictions, min, p99)
```

Это уменьшает влияние экстремальных выбросов модели.

---

## Адаптивная корректировка SI

После предсказания проверяется физическая согласованность:

```text
SI ≈ CC50 / IC50
```

Если модель сильно нарушает связь:
- SI частично корректируется
- сила коррекции зависит от ошибки модели

Это позволяет:
- сохранить распределение предсказаний
- улучшить физическую интерпретируемость результата
